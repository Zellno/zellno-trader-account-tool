# Changelog

## 0.9.0

- adiciona pacote `.deb` para Debian, Ubuntu e Linux Mint;
- adiciona executável independente `.exe` para Windows x64;
- adiciona construção automática e publicação dos binários pelo GitHub Actions;
- adiciona manifesto `SHA256SUMS` aos arquivos de cada Release;
- mantém o mesmo código e as mesmas barreiras de segurança da versão 0.8.0.

## 0.8.0

- primeira versão pública estável;
- adiciona conciliação de auditoria econômica com implantações administrativas;
- valida snapshots, contas, hashes e mudanças de licenças;
- preserva implantação FTP transacional com backup e rollback.
